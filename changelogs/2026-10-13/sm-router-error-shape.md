- Errors the router raises itself (an unknown model route, a key denied a model, an unrepresentable field) now use OpenAI's error shape: `type` is `invalid_request_error`, `permission_error` or `rate_limit_error` by status, an unknown model carries `code: model_not_found` with `param: model`, the router's own key denials carry `code: access_denied`, and the message no longer starts with `API error (N):`. Upstream 401s and 5xx keep `backend_error`.
