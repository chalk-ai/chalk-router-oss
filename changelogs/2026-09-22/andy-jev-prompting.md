- Jev prompting: TypeSafe models now answer OpenAI chat completions (including streaming). The prompt becomes Jev's state and the `response_format` JSON schema becomes its typed questions (`boolean` → yes/no, `string` enum → choice, `integer` levels → score, `number` in [0, 1] → probability); the reply is the schema's JSON object. Prompts without a schema get a 400 that explains the contract. TypeSafe catalog release timestamps are now parsed instead of zeroing `created`.
